# Campus Virtual Universitario

Plataforma web para la gestion integral de procesos academicos desarrollada con arquitectura cliente-servidor.

## Descripcion

El sistema centraliza las actividades academicas entre estudiantes, docentes y administradores. Permite la gestion de cursos, publicacion de contenidos, entrega de tareas, registro de calificaciones y visualizacion de calendarios y notificaciones.

## Tecnologias (estas son las que vamos a llegar a usar)

- Frontend: HTML5, CSS3, JavaScript
- Backend: Java con Spring Boot
- Base de datos: MySQL
- Entorno: Visual Studio Code
